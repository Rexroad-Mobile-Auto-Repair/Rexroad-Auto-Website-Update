# SEO / content-quality rules

Written for the vehicle owner first. If a sentence exists only because
it contains a keyword, cut it.

## Banned patterns

- Keyword stuffing (repeating "{Make} {Model} mobile mechanic Frisco"
  or similar beyond one natural mention)
- City-name repetition beyond what the template already provides in
  the service-area section
- Generic filler that could apply to any business ("we care about our
  customers," "quality service you can trust")
- Mass-produced opening paragraphs — the intro must fail the
  "swap the vehicle name and it still reads true" test from
  `EDITORIAL-CHECKLIST.md`
- Fake FAQs (invented questions with no evidence customers actually
  ask them)
- Invented popularity ("our most requested," "customer favorite") —
  no popularity data exists in the catalog, full stop
- Duplicated make/model content — no paragraph may be copy-pasted
  between two make or model drafts with only the name swapped
- Mechanically swapping vehicle names into otherwise-identical
  copy — every draft must contain reasoning specific to that
  make/model, not a template with blanks filled in

## Positive requirement

Every page must contain genuinely vehicle-relevant editorial
reasoning — a claim, distinction, or piece of guidance that would be
false or nonsensical if you substituted a different make/model. The
"swap test" is the fastest way to check this: read the draft with the
vehicle name changed to something else. If it still reads as true and
natural, it hasn't said anything real yet.
